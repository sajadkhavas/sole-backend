## Architecture decision

SOLE is a clean Laravel 13 modular monolith. Filament 5 is an administration adapter over the same application/domain layer used by the storefront API. MySQL is the production data store. The frontend remains a separate TanStack SSR repository and consumes versioned HTTP contracts.

This boundary avoids inheriting deployment and data assumptions from LBB or Winimi while allowing small, reviewed patterns to be adapted with provenance.
